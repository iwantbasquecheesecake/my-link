### 1.2 세부 컴포넌트 명세 & 인터랙션

#### [1] 네비게이션 헤더
- **로고/타이틀**: 좌측 정렬, `16px` Bold, 은은한 반투명 블러 백드롭 적용 (`backdrop-blur-md bg-white/80` or `bg-[#1E2530]/80`)
- **[🔗 공유] 버튼**:
  - 모바일 터치 영역: `40px × 40px`
  - 인터랙션: 클릭 시 현재 URL 클립보드 복사 + 하단 토스트 팝업(`"링크가 클립보드에 복사되었습니다! 🎉"`) 노출 (2초 후 자동 페이드아웃)

#### [2] 아바타 (프로필 사진)
- **크기 & 형태**: `88px × 88px` 정원형 (`rounded-full`), 테두리 `ring-2 ring-[#00D4EA]/30`
- **시크릿 진입 제스처**: **0.5초 이내에 연속 3회 탭(Triple-Tap)** 시 비밀번호 인증 모달 팝업

#### [3] 실시간 상태 뱃지 (Status Badge)
- **스타일**: 둥근 캡슐형(`rounded-full`), 배경 `bg-[#1E2530]`, 텍스트 `text-[#00D4EA]`, 테두리 `border border-[#00D4EA]/30`
- **인디케이터**: 좌측에 초록색 펄스 점(`animate-pulse w-2 h-2 rounded-full bg-emerald-400`) 배치
- **표시 문구**: 예) `"학부 3학년 재학 중"`, `"졸업 프로젝트 진행 중"` 등 관리자가 직접 설정한 문구

#### [4] 바이오 (자기소개) & [5] 메타 정보
- **바이오**: 최대 3줄, `14px`, 텍스트 색상 `text-[#515160]` (다크 테마: `text-gray-300`), 행간 `leading-relaxed`
- **메타 정보**: 위치 아이콘(`MapPin`) + 거주지/캠퍼스명, 메일 아이콘(`Mail`) + 이메일 주소 (`mailto:` 링크)

#### [6] 소셜 아이콘 바
- **배치**: 중앙 정렬 가로 Flex, 아이템 간격 `gap-3`
- **버튼 크기**: `44px × 44px` 원형/라운드 버튼 (`rounded-xl bg-gray-100 dark:bg-gray-800`)
- **호버 인터랙션**: `hover:scale-110 hover:text-[#00D4EA] transition-all`
- **지원 채널**: GitHub, LinkedIn, Instagram, Email, YouTube, X(Twitter)

#### [7] 카테고리 탭 필터
- **배치**: 가로 스크롤(Horizontal Scroll) 지원, 스크롤바 숨김(`no-scrollbar`)
- **기본 탭**: `전체`, `코드 저장소`, `지도 연구`, `개발 일지` (관리자가 추가한 카테고리 자동 생성)
- **선택 상태**: 
  - Active: `bg-[#00D4EA] text-[#1E2530] font-bold shadow-sm`
  - Inactive: `bg-gray-100 dark:bg-gray-800 text-gray-500 hover:text-gray-900`

#### [8] 리치 링크 카드 (Rich Link Card)
- **카드 규격**:
  - 패딩: `p-4` (`16px`)
  - 둥글기: `rounded-2xl` (`16px`)
  - 배경: 테마에 따라 자동 전환 (기본: `bg-[#1E2530]` 다크 카드 or `bg-white` 라이트 카드)
  - 보더: `border border-[#D6D9E1]/20`
- **내부 요소 배치**:
  - **헤더 라인**: 좌측 카테고리 라벨 + 우측 커스텀 뱃지(예: `bg-[#00D4EA] text-[#1E2530]` 또는 `bg-[#F4F5FB] text-[#515160]`)
  - **본문 라인**: 좌측 Lucide 대표 아이콘(`24px × 24px`) + 제목(`16px font-semibold`) + 이동 화살표 아이콘(`ChevronRight 18px`)
  - **설명 라인**: 부제목/요약글 (`13px text-gray-400 line-clamp-2`)
- **클릭 인터랙션**:
  - 클릭 시 목적지 URL 새 창(`target="_blank"`) 이동
  - 백그라운드에서 해당 링크의 `clickCount`를 `localStorage`에 즉시 1 누적 증가
  - 호버 시 위로 살짝 떠오르는 모션: `hover:-translate-y-1 hover:shadow-lg transition-transform duration-200`

#### [9] 스킬 요약 카드 (Focus & Skills)
- **목적**: 프로필 하단에 핵심 역량(Tech Stack, 관심 분야)을 컴팩트하게 노출
- **디자인**: 서브 카드 형태 (`rounded-xl p-4 bg-gray-50 dark:bg-gray-800/60 border border-dashed border-gray-300 dark:border-gray-700`)

#### [10] 보안 푸터 (Security Footer)
- **표시 내용**: 저작권 문구 (`© 2026 Narin Kim • MyLink`)
- **보안 원칙**: 관리자 로그인 버튼은 화면상에 일절 렌더링하지 않음

## 2. 비밀 관리자 인증 모달 (Secret Admin Auth Modal)
